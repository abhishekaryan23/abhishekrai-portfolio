Image generation · macOS · Apple Silicon · MCP

moss-image-mac

Runs the MOSS-Image 5B text-to-image model locally on an Apple Silicon Mac, about 30 seconds an image on a base M4, and makes it usable from any MCP app such as Claude, Cursor or VS Code. Text inside images comes out right, and you can place elements with bounding boxes, repaint part of an image or make transparent cutouts.

How it works
An MCP server drives stable-diffusion.cpp on Metal: the 5B model in 4-bit with a Qwen3.5-9B text encoder and a FLUX.2 decoder. A 4-step turbo LoRA kept in fp16 replaces the official 50 steps; a high-quality mode reproduces the reference pipeline pixel for pixel. One setup script downloads and checksums everything, and peak memory is about 9 GB.
Built with
Python, stable-diffusion.cpp, Metal, Model Context Protocol, MOSS-Image-SFT, Qwen3.5-9B

Voice · macOS · Apple Silicon

SteerVox

A macOS menu bar app for local-first dictation. Press a shortcut, speak in any app, and the text is pasted back where you were working. Smart Mode turns rough speech into polished text with a local or cloud model.

How it works
MLX Whisper speech recognition on Apple Silicon and Kokoro text-to-speech. When you correct a rewrite, the correction is embedded locally and stored in SQLite with sqlite-vec, and similar past corrections are added to later prompts, so it learns your terms and style offline.
Built with
Python, MLX Whisper, Kokoro TTS, sqlite-vec, Node.js
GitHub
Computer vision · macOS · Apple Silicon

SmartScissor

A native macOS app that segments and clips any object on your screen. Everything runs on the Mac: no image is uploaded.

How it works
A Swift app drives a local Python inference engine running SAM-2 and Florence-2 on the Apple Silicon GPU through Metal Performance Shaders. If the GPU path hits a shape or kernel error, the engine clears the Metal cache and falls back to the CPU. Uses SigLIP embeddings.
Built with
Swift, Python, PyTorch (MPS), SAM-2, Florence-2, SigLIP
